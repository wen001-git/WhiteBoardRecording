# 可书写破纸片需求文档

## 背景与目标

用户希望把具有自然撕裂边缘和纸张纤维感的纸片放到白板上，并直接在纸片上书写。纸片与文字必须表现为一个整体，避免移动或缩放纸片后文字留在原处。

## 核心体验

1. 彩铅贴纸面板新增“纸张便签 / Paper notes”分组，提供 6 款原创无字纸片：暖白、米黄、浅灰各包含横向与竖向版本。
2. 点击纸片后进入画布放置预览；再次点击完成放置，并立即进入纸片内文字编辑。
3. 编辑中支持换行、文字颜色、字体、字号和选区级富文本；Enter 插入换行，点击外部保存，Esc 取消本次编辑。
4. 选中纸片后可整体移动、等比缩放、旋转、复制、粘贴、调整图层和删除；文字始终跟随纸片。
5. 双击纸片或选中后按 Enter 可重新编辑文字。空文字允许保留纸片。
6. 纸片及文字进入文档保存、自动恢复、JSON 导入导出、幻灯片缩略图、笔迹播放与白板录像。

## 视觉要求

- 素材参考用户提供图片的破边纸张气质，但必须重新生成原创轮廓与纹理，不复制参考图中的文字、排版或具体纸片形状。
- 纸片为透明背景位图，边缘自然、不规则，保留细微纸纤维；不含烘焙文字、水印或外部品牌元素。
- 纸张本体不烘焙阴影，由白板绘制轻微投影，确保不同背景下仍有层次且透明边缘干净。
- 默认文字为深灰色手写字体、居中排版，并在撕裂边缘内保留安全留白。

## 权限与兼容

- `whiteboard.html` 创作者版完整开放；商业模板沿用现有贴纸权限，免费用户点击该分组时显示升级提示。
- 继续使用现有 v10 文档容器，以新增可选对象类型保存，不改变旧文档读取行为。
- 两个单 HTML 白板必须保持实现与内嵌素材一致；运行时不得请求外部图片或字体资源。

## 非目标

- 第一版不提供自动排版模板、项目符号、纸片颜色编辑或用户自定义纸张纹理。
- 第一版不提供拆分纸片与文字、自动适应纸片高度或跨纸片链接。
- 不改变普通图片、现有彩铅人物贴纸或普通形状内文字的行为。

## 验收标准

- 6 款纸片均可从“纸张便签”分组放置，首次放置后立即出现可输入光标。
- 输入两行文字并保存后，移动、缩放和旋转纸片，文字位置与比例正确跟随。
- 双击或按 Enter 能重新编辑；Esc 不改变原文字；清空文字只清空内容、不删除纸片。
- 复制粘贴、撤销重做、图层排序、删除、保存后重开均保持纸片与文字为单一对象。
- 两个白板版本的素材、交互和双语标签一致，且 `npm run build:static` 不引入外部运行时资源。
