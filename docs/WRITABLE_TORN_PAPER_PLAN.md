# 可书写破纸片实现计划

## 实现状态

已于 2026-08-26 完成：6 款原创透明 WebP、`paperNote` 复合对象、首次放置即编辑、双语贴纸分组、两个单 HTML 同步、持久化恢复及针对性测试均已落地。

## 阶段一：原创素材

1. 以用户附图仅作风格参考，分别生成暖白、米黄、浅灰的横向与竖向原创纸片。
2. 使用纯色绿幕背景生成，再本地去除绿幕并验证透明角、边缘残色和主体覆盖率。
3. 将成品优化为适合单 HTML 内嵌的透明 WebP；两个版本使用完全相同的数据。

## 阶段二：复合对象模型

1. 新增 `paperNote` 对象：复用图片几何字段与形状标签富文本字段。
2. 扩展绘制、边界、命中、选择、缩放、旋转、缩略图和复制路径，使其表现为单一对象。
3. 纸片缩放时同步缩放默认字号和选区级字号；旋转时文字与纸张使用同一变换中心。

## 阶段三：放置与编辑

1. 在贴纸数据中新增“纸张便签”分组和 6 个 `kind:'paperNote'` 条目。
2. 新增待放纸片流程；完成放置后立即调用纸片标签编辑。
3. 将双击、Enter、样式面板和帮助文案扩展到 `paperNote`，空内容保留纸片。

## 阶段四：双语与同步

1. 在 `locales/zh-CN.js`、`locales/en-US.js` 和动态短语表中补齐分组名、纸片名、帮助与状态文案。
2. 运行 `node scripts/sync-whiteboard-i18n.mjs`，把共享词典同步到两个单 HTML。
3. 保证 `whiteboard.html` 与 `whiteboard-pro.html` 的对象逻辑和素材一致。

## 阶段五：验证与交接

1. 新增针对性静态测试，覆盖纸片分组、复合对象绘制/命中/变换、放置后编辑及两版一致性。
2. 运行新增测试、相关文字/多选/剪贴板测试、i18n 同步检查、内联脚本语法检查与 `git diff --check`。
3. 更新 `docs/IMPL_NOTES.md` 和 `AGENTS.md` 当前状态；不在未获用户明确要求时提交或推送。

## 风险控制

- 素材体积：限制像素尺寸并使用透明 WebP，避免两个单 HTML 继续膨胀。
- 文字溢出：第一版以安全区宽度和手动换行为主，不引入新的自动换行引擎。
- 旧文档兼容：不改变现有对象字段含义，只新增可选类型与字段。
- 录像一致性：纸片和文字必须在同一个 canvas 绘制路径完成，DOM 编辑框继续不进入录像。
